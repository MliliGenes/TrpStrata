# Doto

Unmodified variable font by the Doto Project Authors, bundled under the SIL Open
Font License 1.1 (see `OFL.txt`). Doto is an open-source dotted typeface used for
the Nothing-inspired widget preset; it is not Nothing's proprietary typeface.

Source: https://github.com/google/fonts/tree/main/ofl/doto

Original filename: `Doto[ROND,wght].ttf` (stored here as `Doto.ttf`).
Google Fonts Git blob: `ed8f0db9fb890c570b558941201d1504483f5ebc`.

The desktop helper registers the bundled file with Fontconfig in its own process.
No system font installation or runtime download is required.
